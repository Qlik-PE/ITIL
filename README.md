# ITIL
ITIL 5 Service Intelligence Accelerator

A suite of custom Qlik Sense extensions, governed master items, and demo apps that bring ITIL Incident, Problem, and Change data to life — built for Qlik Cloud and designed to plug straight into a ServiceNow-backed analytics pipeline. Includes purpose-built visualization extensions (Incidents, Problems, Changes), a matching "mission control" dark theme, and the Pipeline Pulse observability layer for tracking data freshness across the full Raw → Conform → Visualize pipeline.

Prepared with love, not microwaved. 🍽️
